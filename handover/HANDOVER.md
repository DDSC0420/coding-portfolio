## Patterns that worked (reuse them)

- Keep rules in a pure module with no framework imports, and test it directly.
- Playwright browser tests, skipped automatically when Playwright isn't installed; locally run with `PLAYWRIGHT_CHANNEL=chrome`.
- The build sandbox can't reach most external sites (e.g. releases.hashicorp.com is blocked; PyPI and GitHub work). To exercise anything that needs the internet or a real tool, do it in a CI job. A `workflow_dispatch` input like `snapshot=true` can commit real outputs back as fixtures (02, 04); `git pull --rebase` afterwards. Trigger with `gh api -X POST repos/DDSC0420/coding-portfolio/actions/workflows/<file>/dispatches -f ref=main -f 'inputs[snapshot]=true'`.
- Look at the result in a browser (screenshot) before calling UI work done; save it to `docs/`. A small Playwright script with the sandbox's `/usr/bin/google-chrome` (channel "chrome") works; quantise PNGs with Pillow (256 colours). For a CLI, render the real ANSI output into a terminal-styled HTML page (04's `scripts/screenshot.py`) and screenshot the window element, not the body.
- Hand-labelled expected answers written from the scenario, never by dumping the tool's output (03, 04's `test_examples.py`, `test_real_plans.py`, `e2e/check_report.py`).
- Ground anything an extractor or model returns against its source, and do interpretation in code (03).
- Plant a known secret in fixtures and assert it never appears in any output (04).
- GitHub Actions gotchas met in 04: a job-level `defaults.run` replaces the workflow's whole `defaults.run`, shell included (Windows then falls back to PowerShell). On Windows runners use `python`, not `python3`; strip `\r` from command output (`tr -d '\r'`); never write `$GITHUB_OUTPUT` lines from Python print. `hashicorp/setup-terraform` needs `terraform_wrapper: false` or it mangles `terraform show -json`. `! cmd` never trips `set -e`.
- FastAPI: don't put `from __future__ import annotations` in a module whose dependencies are functions defined inside the app factory (`Annotated[Ctx, Depends(require_user)]`): the string annotations can't be resolved and every route 422s. Register the error page for Starlette's `HTTPException` so routing 404s get it too.
- A strict CSP (`style-src 'self'`) also blocks inline `style=` attributes: use elements like `<progress>` instead. Any message carried in a URL and shown on the page should be signed (05's `result_page`).
- A dev "time travel" clock should move only the thing being simulated (05: billing time), or it expires sessions mid-demo.
- **This session's git proxy refuses tag pushes (HTTP 403, a policy denial: don't retry or route around it).** Branch pushes to `main` work. So releases get a `workflow_dispatch` path that Kyran starts.
- WebFetch of docs pages may need Kyran's approval (unattended it fails); WebSearch works.
- Sandbox: Python 3.13, make a venv per project under `/home/claude/` (not in the repo). The `gh` CLI works for REST (`gh api`). `apt-get update && apt-get install` works (xdotool came from there). npm registry works; the newest majors (Vite 8, Vitest 5, TypeScript 7, Playwright 1.65) all worked with standard config.
- **Testing a browser extension for real (06):** Playwright can't press extension shortcuts, answer Chrome's permission prompt, or see the toolbar popup. Run headed Chrome under `xvfb-run` and use `xdotool` (`windowfocus` the browser window, then `key alt+shift+h`): Chrome treats it as a real key press and grants `activeTab`. The permission prompt defaults to Deny: `Return` denies, `Tab Return` allows. Reach the real popup from a page CDP session: `Target.getTargets` → `Target.attachToTarget({flatten:false})` → `Target.sendMessageToTarget` with `Runtime.evaluate` (`userGesture:true` counts as a click, so `permissions.request` works). Branded Chrome 137+ ignores `--load-extension`: use Playwright's Chromium or Chrome for Testing (`/usr/bin/google-chrome` in the sandbox is Chrome for Testing).
- **"Registered" is not "visible":** 06's highlights passed every test but weren't drawn, because Chrome ignores `::highlight()` rules in a stylesheet injected with `insertCSS({origin:'USER'})`. Check pixels: 06's harness has a 40-line PNG decoder and samples the screenshot behind each highlight. In CI, take one viewport screenshot (retried) rather than many clipped ones (a clip failed with "Unable to capture screenshot").
- **Deterministic simulation + solver + replay (07):** keep the sim free of clocks, DOM and randomness; a search script finds inputs that reach the goal; tests replay them, and the browser test replays them too (same result = same engine). The solver doubles as a level-design check (it showed two holes were trivial).
- Play-test before calling a game done: 07's first windmill was technically solvable but humanly near impossible (hub in the middle of the gap); a quick "random timing" pass-rate script made the tuning objective.
- Playwright: a hidden element still has its old text, so wait for the panel to be visible before asserting on it and before pressing Enter.
- **Look at the thing, not only the tests (08):** a dashboard screenshot showed a valid workflow marked failed because a worker died holding a step with a retry budget of 1. 224 tests were green. Screenshots of real runs are a test.
- Reaching Kyran's PC: `device_request_folder_access` was refused by the auto-mode classifier; Kyran adding the folder himself (**Add folder** in the desktop app) worked at once. To copy a repo out: `tar czf` inside the connected folder (git bundle needs lock files it can't delete), then `device_stage_files`.
- On Windows, Python writes piped or redirected output in the legacy code page (cp1252): any non-ASCII character (Vite's arrow, a name in a CV) crashes `print`. Reconfigure stdout to UTF-8 where output is data, and name `encoding="utf-8"` on every `read_text`/`write_text`.
- The Claude-side safety check blocks creating public releases (`terraform-drift-release` dispatch was refused): Kyran runs it.
- GitHub runners resolve `localhost` to IPv6: `vite preview` needs `--host 127.0.0.1` when Playwright polls `127.0.0.1`.
- Node 22.18+ runs `.ts` files directly (type stripping) if imports use `.ts` extensions (`allowImportingTsExtensions` + `verbatimModuleSyntax` in tsconfig).
